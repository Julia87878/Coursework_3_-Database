# Проект "Coursework_3_Database"

## Описание:
Проект "Coursework_3_Database" - учебный проект по Python-разработке.
В рамках проекта необходимо получить данные о компаниях и вакансиях с 
сайта hh.ru, спроектировать таблицы в БД PostgreSQL и загрузить полученные 
данные в созданные таблицы.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:Julia87878/Coursework_3_Database.git
```
2. Установите зависимости:
```
poetry install
```

## Использование:
1. Работа по созданию базы данных и таблиц.
Реализован код автоматического создания БД.
Код для создания БД вызывается в основном скрипте программы.
Реализован код для создания таблиц в БД.
Код для создания таблиц в БД вызывается в основном скрипте программы.
Создается таблица для работодателей.
Создается таблица для вакансий.
Использованы средства скрытия данных для доступа к БД.
2. Заполнение данных.
Таблица работодателей заполняется записями о компаниях.
Таблица вакансий заполняется записями о вакансиях компаний.
3. Взаимодействие с базой данных.
Реализован класс DBManager, в котором 5 методов:
Метод получения списка всех компаний и количества вакансий у каждой компании.
Метод получения списка всех вакансий с указанием названия компании, названия вакансии, зарплаты и ссылки
на вакансию.
Метод получения средней зарплаты по вакансиям.
Метод получения списка всех вакансий, у которых зарплата выше средней по всем вакансиям.
Метод получения списка всех вакансий, в названии которых содержатся переданные в метод слова, например менеджер.
4. Интерфейс управления.
Создана функция взаимодействия с пользователем.
Интерфейс взаимодействия с пользователем реализован понятным текстом.
